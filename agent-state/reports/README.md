# Reports

Store bounded, dated audit or verification summaries here only when a durable report is useful.

- Name reports `YYYY-MM-DD-<topic>.md`.
- Include the commit SHA, exact files, commands, summarized results, reviewer, verification date, and blockers.
- Link a report from `CURRENT.md` or `DECISIONS.md`.
- Do not include secrets, customer data, credentials, full transcripts, raw tool logs, or unbounded environment output.
- Keep active task state in `CURRENT.md`; do not let reports become a competing checkpoint system.
